Javna verifikacija

Provjeri dokaz

Zalijepite SHA-256 receipt hasha ili cijeli receipt JSON. Ako je javni verifikator dostupan, stranica će ga pitati; ako nije, dobićete tačan format i komande za lokalnu provjeru — bez lažnog „zelenog".

SHA-256 Ed25519 GTL ledger static fallback

Unos

Hash je 64 heksadecimalna znaka. Ako zalijepite JSON, hash se računa u vašem browseru (Web Crypto) i ništa se ne šalje dok ne potvrdite.

Podaci ne napuštaju vaš browser osim ako endpoint nije dostupan i vi potvrdite slanje.

Šta ćete vidjeti

  • ok
    Potvrđenoreceipt postoji u ledgeru, hash se poklapa, potpis je valjan (ako je ključ postavljen).
  • no
    Nije potvrđenohash ne postoji, ne poklapa se ili je lanac prekinut — sa razlogom.
  • n/a
    Nije moguće provjeritijavni endpoint nije izložen ili traži token. Tada slijedite lokalne komande ispod.

Ova stranica je statična. Ona ne posjeduje ključ i ne može sama izdati potvrdu — može samo prenijeti odgovor verifikatora.

Ručna provjera

Ako endpoint nije javan

Dovoljan vam je javni ključ i receipt. Privatni ključ nikad ne treba napuštati vašu infrastrukturu.

1. Harness endpoint

curl -sS http://127.0.0.1:7125/gtl/verify \ -H "X-Token: $GAMA_TOKEN" \ -H "Content-Type: application/json" \ -d '{"id":"<receipt_id>"}' # ili cijeli objekat: # -d '{"receipt":{...},"result":{...}}'

2. Lokalno, Python

from gama_dsc.sigil import load_public, verify_sigil import json rec = json.load(open("receipt.json")) pub = load_public("gtl_ed25519.pub") res = verify_sigil(rec, result=None, public_key=pub) print(res)
Format: receipt_hash je SHA-256 nad kanonskim JSON-om (sortirani ključevi, bez razmaka, UTF-8). Ako hash računate sami, koristite istu kanonizaciju — inače ćete dobiti različit hash za isti sadržaj.
Primjer

Kako izgleda receipt

{ "decision_id": "dec-216a6d18", "decision_hash": "9f2c…a71b", "tool": "mail", "evidence_kind": "external_send", "verified": true, "reasons": [], "receipt_hash": "5be1…0c9d", "prev_hash": "3ad7…88e0", "key_id": "gtl-2026-11", "sig": "ed25519:base64…", "ts": 1794609572.77 }

Brojevi i hash-evi u primjeru su skraćeni. Stvarni receipt ima punih 64 znaka po hash-u i base64 potpis.
