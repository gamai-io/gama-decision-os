The problem

Agent stacks usually have no answer to three questions

Agents no longer just suggest — they execute: SQL calls, email sends, state changes, invoices. Every action carries risk that must be resolved before the effect.

Question 1

Should this run at all?

Risk, intent and expected evidence must be known before the tool call — not after. The model saying “ok” is not approval.

Question 2

Where does it execute?

Blast radius is chosen by risk: container, gVisor or micro-VM. Untrusted code never runs bare.

Question 3

How do we know it succeeded?

Not from the model’s ok:true, but from independent verification and a signed receipt bound to the decision.

How it works

Three gates, none skipped

1

Decide before the tool

A deterministic precheck and calibrated classifier map the action to a tier: READ, DRAFT, SEND or IRREVERSIBLE. The decision carries an expected_evidence_spec.

p50 2.31 msno LLM call
2

Execute inside a boundary

The sandbox is chosen by risk. SEND and IRREVERSIBLE require an explicit command or human approval; destructive commands are blocked even when the model says “ok”.

runcgVisorFirecracker
3

Prove the effect

The result is checked against the pre-recorded evidence. The receipt carries SHA-256, a link to the decision and a hash chain; with a key it gets an Ed25519 signature.

FAQ

Six questions we hear most

Short answers; deeper context is on the product pages.

Does GAMA replace our agent?

No. Decision OS is middleware between the agent and the tools: it adds a decision before the action and evidence after it. The agent stays yours — OpenCode, Claude, LangGraph or your own loop.

How fast is the decision?

The L0 decision is p50 2.31 ms on a full decide_request (n=500), and the deterministic core is 0.30 ms (n=2000). There is no extra LLM call on that path.

Do we need a cloud?

No. The core runs locally and supports air-gapped installs. Cloud is not required for the decision, receipt or verification; hosted SIGIL is an optional layer.

What exactly does a signed receipt prove?

It proves the tool returned exactly that result at that moment and that the result is bound to the decision that allowed it. With an Ed25519 key it also proves who issued it.

Is Community really free?

Yes, Apache-2.0, with no telemetry and no expiry. Pro and Enterprise add the production build, evidence export, SSO, ERP connectors and SLA.

How do we start?

The first step is one Python call or the harness /health. For production we recommend a 30-minute demo with your scenario, tools and evidence.
