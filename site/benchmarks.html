Metodologija

Kako mjerimo i šta objavljujemo

Cilj nije najljepši broj, nego broj koji drugi tim može ponoviti pod istim uslovima.

Kontrolisani run

Svaki rezultat ima job ID ili tag verzije, fiksiran dataset i zapisan hardver. Run koji nije reprodukovan ne ulazi u tabelu.

Nezavisna provjera

Agentov „ok" se ne računa. Kod se provjerava nezavisnim pytest-om, a iskrenost uporednim gate-om, ne samo modelovom tvrdnjom.

Poštenje o granici

Gdje je set degenerisan ili mjerenje nije završeno, to piše uz broj. Negativni rezultati se objavljuju jednako kao pozitivni.

Reprodukcija

Kako ponoviti mjerenje

Redoslijed je isti za sve tabele: uzmi tačan tag, pokreni skriptu, uporedi JSONL i prijavi odstupanje.

01

Uzmi tačan tag

Koristi verziju iz tabele (npr. CrossNode-Bench v1.4.0), ne main. Tag sadrži dataset i skripte za taj run.

02

Pokreni u istoj granici

Za iskrenost koristi honest i liar varijantu; za kod nezavisni pytest; za sandbox isti kernel i isti režim izolacije.

03

Uporedi sirovi JSONL

Ne poredi samo prosjek. Uporedi pojedinačne zapise, latencije p50/p95 i broj uhvaćenih false-success slučajeva.

04

Prijavi odstupanje

Ako se broj ne poklapa, otvori issue sa job logom i hardverom. Ispravka ide u tabelu, ne u komentar.

Primjer komandi

# 1) klon tačnog tag-a git clone -b v1.4.0 https://github.com/gamai-io/crossnode-bench # 2) pokreni honest i liar run python3 run.py --mode honest --dataset data/v1.4.0.jsonl python3 run.py --mode liar --dataset data/v1.4.0.jsonl --inject node-3 # 3) provjeri rezultat python3 report.py --jsonl out/*.jsonl --p50 --p95
Ograničenja

Šta ovi brojevi ne znače

Nisu garancija za vaš deployment. Latencije zavise od kernela, Python verzije, mreže i opterećenja. Red veličine je stabilan; apsolutni broj nije.
Set može biti lak ili degenerisan. ECE 0.035 je izmjeren na setu gdje je accuracy 1.0; to je realan rezultat na tom setu, ne garancija na težim greškama.
Liar run je kontrolisan. 400/400 znači da gate hvata injektovane laži iz tog scenarija, ne sve moguće oblike prevare u produkciji.
Negativni rezultati ostaju objavljeni. Adapteri nisu pobijedili base model; to je nalaz, ne neuspjeh koji se skriva.
Otkrića

Novosti iz istraživanja

Svaki nalaz nosi datum i kategoriju. Artefakti su na github.com/gamai-io. Pretplata: RSS · zadnja izmjena 2026-11-11.

2026-11-10 · determinizam

LUMI vLLM nije bit-determinističan na temp=0. Dva prolaza kroz 700 zadataka: 660/700 identično (TP=4), 669/700 (TP=1). Needle i tool-JSON 100% stabilni; aritmetika (267–274/300) i iskrenost (93–95/100) variraju. TP=1 smanjio jaz 40→31, pa su uzrok nedeterministički ROCm kerneli/atomics. Repo: gama-lumi-bench.

2026-11-01 · iskrenost

False-success: 6,25% fabrikovanih tvrdnji (25.600 proba). Run na 8 LUMI nodova; evidence gate označio 6,25% lažnih „done" tvrdnji. Verifikacija p50 2,4 ms, p95 10,8 ms.

2026-11-09 · cross-node

CrossNode-Bench: 400/400 laži uhvaćeno. Honest flota 25.600/25.600 (0 false-success); liar run 28.800 proba, 400 false-success — sve 400 uhvaćene na injectovanom nodu. Zenodo DOI 10.5281/zenodo.24092188.

2026-11-09 · model eval

Pošten eval: adapteri nisu pobijedili base model. 678 zapisa (greedy, tools u templateu): base 25/25 tool poziva (100%), 0/50 refusal; najbolji adapter 19/25. Nijedan adapter ne pobjeđuje — RiskGate ostaje obavezan. Objavljeno kao negativan rezultat.

2026-11-01 · CUA

Computer-use: v23 najbolji sa 49%. LUMI grounding (600 uzoraka): v23 49,0% (ScreenSpot 76,3%, UI-Vision 26,3%), tool 95,2%, refusal 100%, multi 100%. Kasniji mixevi (v25–v27) degradirali.

2026-10-12 · sigurnost

Prompt-injection ASR 100% → 0–3,3%. Antibody + source-trust odbrana (sanitize invisible/role markers, nonce fences): uspjeh napada pao na 0–3,3% uz utility 90–100%. Repo: gamai-guard.

2026-11-06 · harness

False-success guard u agent loop-u. Lažni dokazi se redaktuju kada nijedan alat u trajektoriji nije vratio ok:true; screenshots/inventory/SQL fallback vraćaju stvarni status umjesto ok:true.

2026-11-07 · benchmark

AgentMujo-Bench v0.6: 49 slučajeva, 16 kategorija. Sve 16 kategorija pokrivene (uključujući json_validity, terminal_accuracy); 0 preklapanja sa 4.375 trening tekstova; negativne kontrole 0; CI zelen.

2026-10-31 · dataset

AgentMujo dataset v0.4.0. 4.496 redova, 10 datasetova, 13 kategorija, praznine 0. Tool-selection: Qwen3.6-35B-A3B 50%, gpt-oss-120b 56%.

2026-11-07 · agent

Hard user tier: GAMA 11/15 vs opencode 12/12. 15 teških chat zadataka sa Docker verifikacijom. GAMA 11/15 (73%), opencode 12/12; pronađen i popravljen nested-percentage bug („17% of (2400 + 15% of 2400)" → 469,20).

2026-10-22 · infra

General-30: 30/30 @ p50 6,2 s. 30 mješovitih code/research zadataka: 30/30, p50 6,218 s, p95 23,0 s, ~$0,22 ukupno.

2026-10-10 · scale

216 workera ≈ 96% throughput, ali PID limit. Bulk test završio 207/216 (~96%) u ~70 s (~3 zadatka/s). Na 216 workera host je udario u fork limit; sigurni plafon ≈140 workera (load ~39).

2026-11-10 · SIGIL

SIGIL: 1.000 receipta, lanac verifikovan. Gate/verify/anchor lanac validiran end-to-end: 1.000 receipta, 0 grešaka. Svaka akcija je dokaziva Ed25519-potpisanim receiptom.

  • gamai-evals — eval harness: GUI grounding, tool/refusal/multi-step
  • demo — statički dashboard sa izmjerenim dokazima

Security & isolation
