Početna/MCP
MCP server

Alati u vašem MCP klijentu

Model Context Protocol server izlaže provjerene alate Claude Code, Cursor, Codex i OpenCode-u. Klijent dobija samo allowlistu, ne cijelu mašinu.

search_skillsOCRPDFTTSPython sandbox

Alati

  • search_skills — 1.000 vještina
  • make_page — statička stranica
  • ocr, to_pdf, merge_pdfs
  • make_qr, text_to_speech
  • run_python — 30 s sandbox

Instalacija

pip install mcp curl -sL https://gamai.io/mcp/gamai_mcp.py -o gamai_mcp.py claude mcp add gamai -- python /putanja/gamai_mcp.py

Sigurnost

Alati se izlažu po allowlisti. MCP klijent ne dobija shell nad mašinom; svaki poziv može proći kroz Decision OS i SIGIL receipt.

Poveži svoj klijent

Config za OpenCode i Cursor je u GAMACODE dokumentaciji.
